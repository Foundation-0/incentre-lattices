# autoresearch-fold

A small autoresearch-style search rig (after karpathy/autoresearch) for the question "what is the densest ball packing reachable by continuously folding the octahedral bar framework (cube cells of side 2, six dots at c +- (2-sqrt2) e_i, ball radius sqrt2-1, bars of length 2R) without changing any bar length or overlapping balls, when the lattice may shear?". One fixed trusted checker (`verify.py`, hash-locked, builds the bar graph itself and checks bar lengths, overlaps, continuity and rigidity of the end state), one file the agent edits (`search.py`, which writes `out/path.npz`), one scalar metric (max density of a valid path) and a keep-or-discard loop described in `program.md`; `run.sh` runs one experiment with a 3300 s cap (above the 3000 s safety limit in `search.py`) and logs to `results.tsv`, keeping the best valid path in `best/`. Setup: `python3 -m venv .venv && .venv/bin/pip install numpy scipy`; test the checker with `.venv/bin/python test_verify.py`; run `./run.sh`.
